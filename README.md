# Мой день — Android

Личный трекер без аккаунта, сервера и разрешения INTERNET. Android 8.0+.

## Скачать APK

[Скачать установочный APK](../../raw/refs/heads/main/downloads/my-day.apk)

Если браузер показывает страницу файла, нажмите **Download raw file** (значок скачивания). На Android разрешите установку из выбранного браузера. Это отладочная сборка для личного тестирования.

## Использование

1. Установите debug APK, откройте «Мой день».
2. Нажмите «Включить напоминания», разрешите уведомления и точные будильники. После выдачи разрешений нажмите включение ещё раз.
3. На Android 14+ отдельно разрешите полноэкранные сигналы кнопкой на главном экране.
4. Выберите интервал 5, 10 или 15 минут и режим: без звука и вибрации, только вибрация, вибрация + колокольчик. Первый сигнал прозвучит через выбранный интервал. Введите минимум 5 символов без крайних пробелов: появится «Сохранить».
5. История отображается по дням. «Экспортировать всё в .txt» открывает системный выбор файла; UTF-8, даты YYYY-MM-DD и время HH:mm.

Время записи — время сигнала, для ручной записи — время открытия формы. Часовой пояс устройства фиксируется при сохранении. Повторные сигналы не создают очередь пропущенных форм: сохраняется одна ожидающая запись. После перезагрузки включённые напоминания возобновляются с выбранным интервалом. После принудительной остановки приложения Android может блокировать сигналы до повторного открытия.

Android управляет показом окон: на разблокированном экране с разрешением «Поверх других окон» появляется форма, без него — уведомление; на заблокированном возможна полноэкранная форма. Доступ к полноэкранным уведомлениям зависит от версии Android, разрешений и политики устройства. Без него можно открыть форму по уведомлению. Звук и вибрация задаются каналом «Записать занятие» в системных настройках; беззвучный режим, DND и энергосбережение производителя могут влиять на сигнал. Приложение не блокирует системные кнопки: форму можно свернуть без сохранения.

База SQLite находится в приватном хранилище приложения. Резервное копирование отключено; удаление приложения удаляет историю. Экспортируйте её заранее. Выбранное пользователем место экспорта может быть облачным провайдером — для хранения только на устройстве выберите локальную папку.

## Разработка

JDK 17 или 21, Android SDK platform 35, build-tools 34.0.0, Gradle 8.9.
Укажите путь к SDK через ANDROID_HOME или локальный (не сохраняемый в Git) local.properties.

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка на устройстве

Проверить включение и отключение; реальный сигнал через 5, 10 и 15 минут при заблокированном экране; режим без полноэкранного разрешения; скрытие кнопки для 0–4 символов; сохранение текста, включая переносы и кириллицу; историю после перезапуска; экспорт и переход даты через полночь. Эмулятор/телефон нужны для проверки уведомлений и поведения фоновых будильников.

### Текущая облачная среда

SDK и Gradle подготовлены вне репозитория. Для повторной сборки в этой машине:

```sh
cd /workspace/productivity
export ANDROID_HOME=/workspace/android-tools/sdk
export ANDROID_USER_HOME=/workspace/android-tools/android-user
export GRADLE_USER_HOME=/workspace/android-tools/gradle-home
/workspace/android-tools/gradle-8.9/bin/gradle :app:assembleDebug :app:lintDebug --no-daemon
```

Настройки прокси и доверенный сертификат среды находятся вне репозитория. Для обычного Android Studio они не требуются.

## Версия 1.1

Тёмно-синий анимированный градиент, настройки интервала 5/10/15 минут и три режима сигнала. Колокольчик встроен в приложение и работает без сети. При изменении интервала следующий сигнал отсчитывается заново; выбор режима не меняет время следующего сигнала. Настройки сохраняются после закрытия приложения.

Для коротких интервалов используются системные будильники: Android может показывать значок ближайшего будильника. Системные настройки каналов уведомлений имеют приоритет над настройками приложения. При обновлении установите APK поверх предыдущей версии, не удаляя её, чтобы сохранить записи.

Проверка на телефоне для 1.1: все три интервала при погашенном экране, отсутствие звука и вибрации в тихом режиме, только вибрация во втором режиме, приложенный колокольчик и вибрация в третьем, сохранность настроек после перезапуска и истории после обновления.

## Версия 1.2: форма поверх экрана и фоновая сессия

После обновления откройте приложение и выдайте разрешения:

1. «Разрешить полноэкранные сигналы» на Android 14+ — для формы на экране блокировки. На более ранних версиях проверьте системные настройки канала уведомлений и показ на экране блокировки.
2. «Разрешить форму поверх приложений» — для автоматической формы на разблокированном экране. Форма сворачивается кнопкой «Свернуть», запись не теряется из ожидающих.
3. «Снять ограничения батареи». На Xiaomi, Samsung, Huawei и других оболочках дополнительно проверьте автозапуск и режим «Без ограничений»/исключение из спящих приложений.

При включённых напоминаниях работает foreground service с постоянным уведомлением и кнопкой «Выключить». Служба не привязана к экрану приложения и запрашивает перезапуск после завершения процесса системой. Смахивание задачи из недавних не выключает напоминания; расписание хранится также в системном AlarmManager. После перезагрузки (и первого разблокирования) и обновления APK включённая сессия восстанавливается.

Android и прошивки могут ограничивать показ поверх окон, фоновые службы и автозапуск. Системная кнопка «Остановить» и принудительная остановка приложения имеют приоритет: приложение не обходит их. После принудительной остановки откройте приложение снова. Нулевой расход батареи и гарантированную работу при любых ограничениях обеспечить невозможно; постоянные wake lock и опрос таймером не используются.

Проверка на устройстве для 1.2: выдать разрешения, включить интервал 5 минут, смахнуть приложение из недавних и дождаться формы; повторить с заблокированным экраном; проверить сохранение, сворачивание формы, появление клавиатуры и отключение из постоянного уведомления. Проверить восстановление после перезагрузки и первого разблокирования, отзыв разрешений и отказ от них. Фоновая служба и оверлей в облачной среде без Android-устройства функционально не проверены.
