# Мой день — Android

Личный трекер без аккаунта, сервера и разрешения INTERNET. Android 8.0+.

## Скачать APK

[Скачать установочный APK](../../raw/refs/heads/main/downloads/my-day.apk)

Если браузер показывает страницу файла, нажмите **Download raw file** (значок скачивания). На Android разрешите установку из выбранного браузера. Это отладочная сборка для личного тестирования.

## Использование

1. Установите debug APK, откройте «Мой день».
2. Нажмите «Включить напоминания», разрешите уведомления и точные будильники. После выдачи разрешений нажмите включение ещё раз.
3. На Android 14+ отдельно разрешите полноэкранные сигналы кнопкой на главном экране.
4. Первый сигнал прозвучит через 15 минут. Введите минимум 5 символов без крайних пробелов: появится «Сохранить».
5. История отображается по дням. «Экспортировать всё в .txt» открывает системный выбор файла; UTF-8, даты YYYY-MM-DD и время HH:mm.

Время записи — время сигнала, для ручной записи — время открытия формы. Часовой пояс устройства фиксируется при сохранении. Повторные сигналы не создают очередь пропущенных форм: сохраняется одна ожидающая запись. После перезагрузки включённые напоминания возобновляются с новым интервалом 15 минут. После принудительной остановки приложения Android может блокировать сигналы до повторного открытия.

Android управляет показом окон: на разблокированном экране обычно появляется уведомление; на заблокированном возможна полноэкранная форма. Доступ к полноэкранным уведомлениям зависит от версии Android, разрешений и политики устройства. Без него можно открыть форму по уведомлению. Звук и вибрация задаются каналом «Записать занятие» в системных настройках; беззвучный режим, DND и энергосбережение производителя могут влиять на сигнал. Приложение не блокирует системные кнопки: форму можно свернуть без сохранения.

База SQLite находится в приватном хранилище приложения. Резервное копирование отключено; удаление приложения удаляет историю. Экспортируйте её заранее. Выбранное пользователем место экспорта может быть облачным провайдером — для хранения только на устройстве выберите локальную папку.

## Разработка

JDK 17 или 21, Android SDK platform 35, build-tools 34.0.0, Gradle 8.9.
Укажите путь к SDK через ANDROID_HOME или локальный (не сохраняемый в Git) local.properties.

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка на устройстве

Проверить включение и отключение; реальный сигнал через 15 минут при заблокированном экране; режим без полноэкранного разрешения; скрытие кнопки для 0–4 символов; сохранение текста, включая переносы и кириллицу; историю после перезапуска; экспорт и переход даты через полночь. Эмулятор/телефон нужны для проверки уведомлений и поведения фоновых будильников.

### Текущая облачная среда

SDK и Gradle подготовлены вне репозитория. Для повторной сборки в этой машине:

```sh
cd /workspace/productivity
export ANDROID_HOME=/workspace/android-tools/sdk
export ANDROID_USER_HOME=/workspace/android-tools/android-user
export GRADLE_USER_HOME=/workspace/android-tools/gradle-home
/workspace/android-tools/gradle-8.9/bin/gradle :app:assembleDebug :app:lintDebug --no-daemon
```

Настройки прокси и доверенный сертификат среды находятся вне репозитория. Для обычного Android Studio они не требуются.
